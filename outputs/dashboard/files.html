How the pages connect to evidence

A simple, auditable workflow
Original inputs → notebooks 01 and 02 → evidence tables in outputs/ → dashboard pages and figures.
  • ✓Source files are not edited during analysis; the notebooks verify their fingerprints.
  • iEvery dashboard panel names the output file its numbers come from.
  • imanifest.json beside this page lists every file shown here with its category and size.

Before submission

Reproducibility checks to complete
  1. Run notebook 01, then notebook 02, each from a fresh kernel.
  2. Run python -m pytest -v and update the validation notes.
  3. Confirm the dashboard numbers against the files above (each panel cites its source).
  4. Check that raw inputs are unchanged: both notebooks end with a fingerprint check.
