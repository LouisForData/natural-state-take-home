How to read these pages

Conventions used throughout
  • Status is never colour alone. Every coloured mark carries an icon and a label.
  • Flags request review. No field value, name or coordinate is corrected.
  • A fitted 99% is not certified precision. No species reaches 99% on a strict lower bound; that would need about 299 error-free checks.
  • Recall is unavailable. Calls BirdNET missed were never annotated.
  • Every panel names its source file in outputs/, so each number can be traced.
